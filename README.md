### BoltSync at a glance

- **Desktop app:** Electron, React, TypeScript, Node.js, PostgreSQL
- **Accounting:** sales, purchases, returns, stock with IMEI tracking, day closing, a double-entry ledger and 20+ reports
- **Runs offline:** several PCs in one shop share a database over the local network
- **Licensing:** paid plans that work offline, using signed device licences
- **Safety:** 130 database migrations shipped to live shops without losing data, encrypted backups to Google Drive, and 110 automated test files
- **Releases:** auto-updating Windows installer, now on v1.0.9 ([downloads](https://github.com/Alternat1v3/billing-releases/releases))
